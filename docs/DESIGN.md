# Interface direction

Nate's correction: minimal, terse, focused; not a marketing site. Easy to read, no Gruvbox / muted earth-tone theme. Rybitten is a color reference, not a layout reference.

Use a paper-white and ink base, with a clear blue inspired by RYBitten's Itten gamut. No gradients, muted green text, decorative panels, oversized marketing titles, numbered experiment eyebrows, stacked introductions, empty reassurance, icon tiles, or slogan footers. Keep working controls and evidence prominent.

UI system sans, body 14px, source 12–13px monospace. Metadata >=12px. Text contrast should be readable. Border radius 3–4px; no card shadows. Spacing 8/12/16/24. No decorative grids. Accent for active controls and links; semantic color only for statuses/diffs. Common panels get 14px heading and 12px description; avoid redundant descriptions. Use compact top navigation and a plain linked index.

Keep functionality and evidence prominent. Omit redundant introductory copy and ornamental icon blocks. Keep short truthful provenance, uncertainty, and actionable error states. Prefer concise labels: Query, Analyze, Compare, Source, Results, Workflow, Intent, Context, Budget, Run, Event. Source text is evidence: preserve it when changing the design.
